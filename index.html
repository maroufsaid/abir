A few useful checks

Weather or location looks wrong

Check Location in Abir’s Settings for a manually selected city, and review Abir’s location permission in iOS Settings. Without live weather, Abir can show a seasonal estimate.

Your collection is not syncing

Check that your devices use the same Apple account and that iCloud is available for Abir. Allow time for sync to finish. Contact support before deleting or reinstalling the app if data appears to be missing.

A fragrance is missing

You can add a custom fragrance. If you email a catalogue suggestion, include the fragrance name and brand.
